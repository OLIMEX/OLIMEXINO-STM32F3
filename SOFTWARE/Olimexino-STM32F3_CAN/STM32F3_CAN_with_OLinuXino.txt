We have to initilize the CAN module the same way as the STM32F3. At the CAN connector pins 1 and 2 have to be corssed (H and L are swapped).

Initialization (OLinuXino side):
ip link set can0 down
ip link set can0 type can bitrate 1000000
ip link set can0 up

Receiving (OLinuXino side):
candump can0

Sending (from OLinuXino to STM32):
cansend can0 103#00.01.02.03.04.05.06.07
